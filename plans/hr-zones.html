Garmin Fenix 7 Pro — Setup Instructions

Two methods: watch directly or Garmin Connect app (easier for typing numbers)
📱 Garmin Connect App
⌚ On the Watch
  1. Open Garmin Connect
    Tap the menu icon (three lines) at the bottom right of the screen.
  2. Navigate to your device
    Tap Garmin Devices → select your Fenix 7 Pro.
  3. Open User Settings
    Scroll down to User Settings → tap Heart Rate Zones.
  4. Set Max Heart Rate to 183
    Tap the Max HR field and enter 183. This anchors all zone percentages correctly.
  5. Switch to Custom mode
    Change the calculation method from "% of Max HR" to Custom (BPM). This lets you enter exact numbers instead of percentages.
  6. Enter zone boundaries
    Set each zone lower boundary exactly as shown below.
    Enter these values — lower boundary of each zone
    • Zone 1 (Easy)92 bpm
    • Zone 2 (Aerobic)119 bpm
    • Zone 3 (Tempo)137 bpm
    • Zone 4 (Threshold)155 bpm
    • Zone 5 (Maximum)168 bpm
  7. Save and sync
    Tap Save. Make sure Bluetooth is on and the watch is nearby — settings sync automatically within a few seconds. Confirm on the watch that the zones updated.
App method is recommended — entering numbers on the Garmin Connect phone app is much faster than scrolling up/down on the watch buttons. The sync is automatic and instant over Bluetooth.
  1. Enter the menu
    From the watch face, press and hold the UP / MENU button (upper left button) for 2 seconds until the settings menu appears.
  2. Navigate to User Profile
    Scroll down using the UP/DOWN buttons and select:
    Menu → Settings → User Profile
  3. Open Heart Rate settings
    Inside User Profile, scroll to and select Heart Rate.
  4. Set your Max HR
    Select Max. HR → scroll to 183 → press the START/SELECT button (top right) to confirm.
  5. Open HR Zones
    Scroll to HR Zones and select it. The watch may show zones as % of max. To enter custom BPM values, look for Custom mode and select it.
  6. Set each zone
    For each zone (1 through 5), scroll to the lower boundary number and enter the values below using UP/DOWN to increment. Press START to confirm each value.
    Lower boundary for each zone
    • Zone 192 bpm
    • Zone 2119 bpm
    • Zone 3137 bpm
    • Zone 4155 bpm
    • Zone 5168 bpm
  7. Save and exit
    Press the BACK button (lower left) to save and exit. The zones are stored immediately on-device — no sync needed when setting directly on the watch.
Tip: Scrolling number-by-number on the watch to reach 183 takes a while. Long-press UP to scroll faster. The Garmin Connect app method (other tab) is significantly quicker for entering exact BPM values.

Set Zone 2 HR Alert on Watch

Alerts you when you cross 136 bpm — your hard ceiling
  1. Start a Run or Bike activity
    Press the START button → select your activity type (Running or Indoor Cycling).
  2. Open activity settings
    Before starting, press UP/MENU → scroll to Alerts.
  3. Add a Heart Rate alert
    Select Heart Rate → set alert type to High Alert → set value to 136 bpm. The watch will beep and vibrate if you cross it.
  4. Save alert to activity profile
    This can be saved to your Running and Indoor Cycling profiles permanently via Garmin Connect → Activity Profiles → Alerts, so you don't have to set it each session.
